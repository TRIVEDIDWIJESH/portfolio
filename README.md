# Dwijesh Trivedi – Portfolio
React + Vite + vanilla CSS.

    npm install
    npm run dev      # local
    npm run build    # production build -> dist/

Deploy: push to GitHub, import the repo in Vercel (Framework: Vite, build `npm run build`, output `dist`).
Update the LINKS object at the top of src/App.jsx with the real GitHub, LinkedIn and Portfolio URLs.
